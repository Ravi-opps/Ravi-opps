### About

I build systems end to end — the ingestion path, the retrieval layer, the API, and the interface someone actually clicks. A project isn't finished for me until it runs, fails loudly when it should, and can be demoed.

Most of what I know came from shipping something and then fixing what broke: a parser that had to preserve document order, ingestion that couldn't block the request path, a build pipeline that had to survive a container dying halfway. I read the source, find the bottleneck, and keep the thing running.

- Computer Science at **MGIT**, Hyderabad
- Ships with Python, TypeScript, FastAPI, Next.js, Kafka, Docker, Postgres, Redis, and Qdrant
- Learning how systems scale now; **distributed systems** next

### Featured work

| Project | What it is | Stack |
| --- | --- | --- |
| [**SEC Filings RAG Assistant**](https://github.com/Ravi-opps/SEC-filings-RAG-Assistant) | Structure-aware RAG over 10-K, 10-Q, and 8-K filings. Answers carry sentence-level citations that link back to the exact passage on EDGAR. Kafka + Redis ingestion, Qdrant retrieval with reranking, a LangGraph planner, and a guardrail that blocks off-topic prompts and prompt injection before retrieval runs. | `Python` `FastAPI` `LangGraph` `Qdrant` `Kafka` `Next.js` |
| [**Noesis**](https://github.com/Ravi-opps/Noesis) | Product-feedback intelligence platform that turns unstructured community discussion into evidence-backed sentiment and concrete product recommendations. JWT auth, Postgres, Redis-backed caching, and a Groq + ChromaDB RAG endpoint. | `TypeScript` `React` `FastAPI` `Postgres` `Redis` `ChromaDB` |
| [**Ravicel**](https://github.com/Ravi-opps/ravicel) | A lightweight deployment platform: hand it a GitHub repo and it clones the source, builds it in Docker, uploads the assets to Azure Blob Storage, and serves the site under a four-character ID. Five services stitched together over Kafka. | `Python` `FastAPI` `Kafka` `Docker` `Azure` |
| [**Amazon ML Challenge**](https://github.com/Ravi-opps/Amazon-ML-challenge-Sub) | Competition submission covering feature engineering, text handling, and model selection on a large product-metadata dataset. | `Jupyter` `Python` `scikit-learn` |
